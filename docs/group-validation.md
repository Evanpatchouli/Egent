# Egent 0.3.0：多人会话与托盘验收

日期：2026-09-15。用户已确认实施，并追加：不要求保留旧数据、关闭窗口到托盘、第一步允许不选同事。

## 交付行为

- 所有参与会话统一展示，按项目设备 ID 与项目路径分组；同名项目不会跨设备合并。
- 新聊天两步：可选的多人邀请、所属人 → 开放项目选择。支持直接创建个人会话。
- 会话绑定单个项目，创建后 API 不接受修改，SQLite trigger 同时禁止修改 projectPath。
- 后续成员只读取加入后的历史。历史游标、未读、标题及任务使用同一权限边界；加入前触发的 Agent 任务后续输出也不向新成员回放。
- 同事列表展示在线/离线；Material Tailwind Menu 支持右键、点击和键盘打开重连。检测与连接均绑定原设备 ID/公钥。
- 关闭 Electron 窗口只隐藏；双击托盘或“打开 Egent”恢复，“退出”通知后端停止。

## 自动化验证

`pnpm test`：22 项/组服务端测试 + 1 项桌面生命周期测试通过。

- 原 HTTP、Socket.IO、CLI 执行器、SQLite 幂等、简单/复杂 Agent 确认回归。
- 四独立后端：发起人、项目所属人、初始成员、后加入成员。各自使用新 SQLite、设备 ID 和密钥。
- 三人创建和项目候选聚合；创建重试不重复；禁止更改项目；不同项目设备的会话统一汇总。
- 非成员无法枚举、打开或读取会话；Owner 无非成员旁观特权。
- 后加入成员的初始消息/未读为零，旧标题隐藏，before/after/已读旧消息游标拒绝；新消息分页、未读与重复邀请边界正确。
- 后加入成员通过本机 Socket 向远端项目发送，收到新消息且不重放旧消息。
- 项目设备离线时本地缓存只包含可见记录，发送拒绝；相同设备在新端口重启后恢复会话；错误设备地址被拒绝。
- SQLite 级验证旧 Agent 输出、任务错误及标题不泄露，新的可见任务正常返回。
- 桌面生命周期测试使用真实 main.cjs 和模拟 Electron 事件：close 阻止销毁、不停止后端；托盘打开/双击/第二实例恢复窗口；托盘退出只发送一次 shutdown。

## 实际 UI 与 Electron

使用 Playwright CLI 操作实际前端，未用模拟 API 替代业务请求：

- 不选同事 → 本机项目 → 个人会话 → 发送早期记录 → 后续邀请。
- 选择历史同事并输入另一人的 IP，选择两人；项目选择器出现自己和两位同事，选择同事项目创建三人会话并发送。
- 相同路径、不同所属人的项目分别成组；右键菜单进入重连，错误身份地址使连接按钮保持禁用，正确地址可检测并连接。
- 受控 Checkbox 的选中发生在握手完成后；CLI 的即时 `check` 曾因异步选中报错，改用点击并等待成功状态验证。生产控件本身会在连接中禁用，完成后才选中。
- 720×580 小窗口：弹窗边界 y=20..560，底部操作 y=484..541，均在视口内；中部内容可滚动。无嵌套 label。
- Material Tailwind Menu 已单独复测右键打开及重连操作；原测试故意使用错误设备时产生预期 HTTP 503，不是脚本异常。

实际 `release/win-unpacked/Egent.exe` 验证：

- 启动内置后端、设置昵称、创建个人会话、发送成功。
- 实际窗口内容尺寸 1264×821，无横向/纵向页面溢出，页面脚本异常为零。
- `BrowserWindow.close()` 后 isVisible=false，后端健康检查可用；另一独立设备仍能发送消息到隐藏窗口的会话。
- 第二实例事件恢复原窗口；调用托盘退出使用的 app.quit 路径后进程关闭、监听端口不可用。
- 原生系统托盘鼠标点击未由桌面自动化点击；菜单回调由生命周期测试覆盖，真实隐藏/恢复/退出及后台收信由发行 EXE 覆盖。

## 边界

项目所属设备仍为会话权威端，其他成员在线不能替代它；它离线时只能读取已同步副本。最多 20 人；邀请即加入，无额外审批。没有公共服务器、中继、跨设备 typing 或旧版本数据转换承诺。真实模型实施未在业务工作区执行，测试不会改动用户项目文件。
