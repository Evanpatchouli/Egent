# Egent 0.4.0：智能参与与显式任务

日期：2026-09-15。最终范围包含用户追加确认的默认智能参与、Material Tailwind Switch、仅项目所属人可切换，以及点击 Egent 头像插入提及。

## 行为与权限

- 会话默认开启智能参与；只有项目所属人可切换，其他成员看到禁用的 Switch 和“仅所属人可修改”。权限由项目端计算，不能使用访问端本机的 Owner 角色判断。
- 普通消息等待约 4 秒合并后进行一次只读判断，模型可选择沉默；主动回复之间至少约 30 秒。没有新用户消息不自我触发。
- 判断期间有新消息、成员加入、开关变化，即使关后再开，也会丢弃旧草稿。关闭不影响显式 @Egent 和任务操作。
- 自动判断只用全体当前成员共同可见的最近非任务消息；显式问答/任务只用该次请求和显式补充。提示词禁止读取 Egent 数据目录或其他聊天记录。
- 自主参与和 @Egent 都调用只读沙箱。代码修改必须创建任务、审阅方案并点击带版本的确认按钮；自然语言“确认”不授予执行权限。
- 简单任务由请求者或项目所属人确认，复杂任务仅项目所属人确认。可见成员可补充待确认任务；补充后重新分析，新版方案重新确认。
- 多个任务可并存。确认后排队，当前设备单工作线程串行模型阶段，保证同项目跨会话写入互斥；并未增加不同项目并行执行。排队取消不启动 CLI，实施中断不自动重做。
- 点击聊天中 Egent 的头像，或输入框顶部的 `@Egent` 按钮，在光标处插入 @Egent，保留草稿、聚焦、不重复已有提及、不自动发送。头像使用 Button/Avatar，支持键盘。按钮在已提及时显示灰底和取消 X；成员菜单及头像提及的验收见 [会话提及](mentions-validation.md)。

## 自动化验证

`pnpm test`：30 项/组服务端测试与 1 项 Electron 主进程生命周期测试通过。权限收紧后，另重跑 groups/participation 的 8 项/组针对性验证，通过。

- 原身份、直连、缓存、四设备多人会话、后加入成员历史边界、Socket.IO、CLI 沙箱和取消/超时回归。
- 智能参与关闭时普通聊天零模型调用；显式 @Egent 即使要求改代码也不会实施。
- 自主判断可沉默而不产生消息或任务；冷却、关闭、无新消息不重入；关闭再开启也不会发送旧草稿。
- 成员变化丢弃生成中的旧回答，新一轮上下文不含加入前的测试私密文本。
- 普通聊天和自然语言确认不会进入任务上下文或执行；补充产生 v2，旧版和未授权用户确认被拒绝，重复确认只执行一次。
- 同项目不同会话的已确认任务保持串行；排队中的第三项取消后不运行。
- 项目所属人可配置开关；同事通过本机 HTTP 转发到项目设备时仍返回 FORBIDDEN，不能因自己本机是 Owner 而越权。

## 实际浏览器验证

使用 Playwright CLI、两个独立后端与 SQLite，后端仅在 test/agent-fixture.ts 注入确定性测试执行器，不调用真实模型或修改项目文件。该 fixture 不进入发行包。

- 默认开启时，发送普通问题，收到自主回复；它不是一个开发任务。
- 关闭后 @Egent 仍返回只读答案。
- 创建任务、审阅 v1、普通聊天发送“确认”仍等待、补充生成 v2、点击“确认并执行 v2”后收到结果。
- 项目所属人页面可切换；同事页面 Switch 禁用；所属人切换后同事页面同步状态。
- Switch 鼠标和键盘 Space 可操作；头像连续点击和键盘 Enter 保留草稿，仅一个 @Egent 提及，焦点回到输入框且消息数不增加。
- 已检查常规窗口及 720×580 小窗口。浏览器无页面错误。一次精确文本等待因回答段落还包含引用依据而超时，改以实际段落内容核验；不是服务未回复。
- 截图：output/playwright/agent-plan.png、agent-small.png、agent-avatar.png。早期 plan 截图来自权限收紧前的同事页，最终权限以 avatar 截图及接口测试为准。

## 实施边界

只读参与判断即使不回复也可能消耗模型调用。关闭会丢弃在途回答，但只读 CLI 可能继续结束。当前不是逐字流式聊天，也未增加完整 diff 浏览器或自动提交。测试执行器不代表真实模型的发言质量；CLI 参数与结构化结果处理已有回归，真实业务项目实施未作为默认验收。

## 发行 Electron 实测

直接运行最终 win-unpacked/Egent.exe，与独立测试项目设备连接：同事端 Switch 禁用；点击 Egent 头像保留草稿并添加提及；显式问答返回；创建开发任务、按钮确认并显示结果通过。关闭窗口保持后台，第二实例恢复窗口，显式退出正常，页面异常为零。结果保存在 output/playwright/agent-electron-result.json，截图 agent-electron.png。模型仍为远端测试执行器，未对真实项目实施修改。
