# 同事添加入口与在线比

- 同事标题最右侧增加 Material Tailwind Ghost Button 加号，数字改为后端 online 为 true 的人数 / 联系人总数，无联系人时显示 0/0。
- 添加弹窗先通过 `/api/peers/probe` 查找并展示昵称和地址，再使用返回的地址和 deviceId 调用 `/api/peers/connect`。修改地址会清除验证结果；查找或添加中锁定输入及关闭，失败可重新查找。
- 添加成功立即更新侧栏并重新读取联系人，按设备 ID 去重。沿用每 3 秒刷新一次的连通性状态；不会创建会话或邀请同事进入已有会话。
- 沿用后端已有设备身份、公钥校验及本机令牌权限，无新增 API 或数据库变更。
