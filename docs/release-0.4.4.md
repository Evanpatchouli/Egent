# 0.4.4 最小化 Logo 优化

- 最小化 Logo 距聊天区右边缘从 12px 调整为 28px。
- 使用两层阴影、手形光标；悬停时浅底、上浮 2px 并加深阴影，按下缩放至 96%。覆盖 Material Tailwind Ghost Button 的 focus/hover shadow-none，焦点状态仍保留阴影。
- 有活动任务时左上角显示 22px 动态角标，旋转周期 0.8 秒。优先展示执行，其次分析，最后排队；悬停提示对应“正在执行”“正在思考”“正在排队”。
- 无活动任务、等待用户确认、完成、失败、取消或设备离线时移除角标。以当前可见任务数据为准；后台自动参与判断没有独立前端运行状态，不虚构忙碌状态。
- 系统开启减少动态效果时关闭按钮位移和角标旋转，保留阴影、颜色及静态角标。
