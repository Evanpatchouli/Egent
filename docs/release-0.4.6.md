# 0.4.6 启动页

- Electron 就绪后立即创建白底主窗口并加载本地 splash.html，再启动后端；服务就绪后复用同一窗口加载应用。
- Logo 居中，下方文案“Egent 启动中”，文字采用 1.2 秒循环流光。系统减少动态效果或强制颜色时使用静态可读文字。
- 桌面静态启动页、前端初始 HTML、React 身份初始化共用 splash.css，避免初始化过程中出现旧文字提示。
- 保持 renderer sandbox、contextIsolation、禁止 Node、外部导航、外部窗口和权限请求。静态启动页禁用脚本，仅加载本地样式及图片。
- 不设置最短展示时间。便携启动器自解压发生在 Electron 启动之前，本页面不覆盖该解压阶段。
- 同时包含会话右上角的“用户＋”邀请图标。

## 验证

- 桌面生命周期测试通过：服务就绪前存在启动窗口、只加载一次应用、复用窗口、启动期间关闭隐藏到托盘、后台就绪不弹回、托盘恢复和退出行为正常。
- 完整前后端构建、ESLint 和格式检查通过。
- 浏览器加载发行目录中的静态启动页，确认白色背景、Logo 加载、居中布局及 startup-shimmer 动画生效。
- 未启动真实模型或额外的业务后端。
