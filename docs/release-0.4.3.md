# 0.4.3 浮动任务面板

## 交互

- 任务面板从文档布局中移出，聊天区不再为面板预留高度。
- 默认小浮窗吸附消息区右上角，宽度 320px、最大高度 320px；空间不足时按消息区尺寸收缩。内部内容独立滚动。
- 右上角提供最小化、最大化按钮。最小化后隐藏整个面板，只在消息区右侧显示应用 Logo 头像，点击恢复小浮窗。
- 最大化时在消息区中央展示，宽度最大 760px，高度随消息区扩展，保留边距且不遮挡下方输入框。右上角变为最小化、收起；收起回到原来的小浮窗。
- 最小化保持组件挂载，任务轮询、操作请求和已展开详情继续保留。恢复时聚焦面板按钮；Esc 在大面板中收起，在小面板中最小化。
- 智能参与、创建任务、方案详情、确认执行、补充需求和取消任务沿用现有权限及接口。

## 验证

完整前后端构建、修改文件的 ESLint 和 Prettier 检查通过。浏览器验证使用真实 AgentStatus、FloatingTaskPanel 和 Composer，网络请求在验证页内模拟，不调用真实后端或模型。

验证页：运行前端 Vite 后访问 `/test/floating-tasks.html`，不会进入发行包。

已验证：

1. 默认小浮窗为 320×320px，右上定位，不改变消息区布局。
2. 1280×720 窗口下，大面板宽 760px，中心与消息区中心一致，边缘保留约 16px。
3. 最小化后面板隐藏，仅显示 Logo，聊天仍可输入和发送。
4. 恢复后保留原先展开的方案详情；最大化、收起恢复小窗尺寸正常。
5. 创建任务弹窗可打开并取消；模拟确认执行后显示排队状态。
6. Esc 正确执行收起、最小化；浏览器控制台无错误。

未进行真实模型调用和多设备联调。
