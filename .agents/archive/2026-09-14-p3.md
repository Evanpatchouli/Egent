## 数据与业务规则

- 新增 Conversation：UUID id、projectPath、title 默认“新聊天”、createdByUserId、createdAt、updatedAt，关联创建者。
- 新增 ConversationParticipant：UUID id、conversationId、userId、joinedAt、lastReadAt（初始空）；唯一 conversationId+userId，不额外加已读表。
- 新增 Message：UUID id、conversationId、USER/AGENT/SYSTEM senderType、可空 senderUserId、clientMessageId、TEXT content、createdAt。原生 CHECK 保证 USER 消息有发送者和 clientMessageId；唯一 conversationId+senderUserId+clientMessageId。AGENT 只留枚举和展示类型，不开放客户端伪造 senderType。
- 消息按 createdAt+id 稳定排序、游标分页；默认 50，上限 100，before 游标必须属于当前会话。返回 items 正序、hasMore、nextCursor。
- 同一会话消息写入时在数据库事务内串行化，保证第一条 USER 消息只设置一次标题，并与消息/updatedAt 更新原子提交。标题去除换行、最多 40 code points 加省略号；纯文本内容限制 1–10000 code points。
- 创建会话时重新读取 Codex 配置和 visibility，事务创建会话及创建者 participant；可以写一条服务器生成的 SYSTEM 创建提示，不生成 Agent 消息。
- Owner 可列出所有会话，进入详情或 join 时幂等加入 participant。同事只能列出/读取/加入自己已有 participant 的会话，不提供任意同事自助加入陌生会话。
- 发送前所有角色都必须是 participant。HTTP 与 Socket 共用同一服务，clientMessageId 重试返回已有消息；同一键不同内容返回 409，不写第二条、不重复广播。
- visibility 和 config 是否存在只控制新建；历史会话读取、发消息、分组不再依赖当前配置。已移除项目用历史 projectPath 推导名称，可标记为历史项目。
- unread 按 participant 已读边界统计他人消息；Owner 尚未加入时视为未读。仅将前端实际显示的最后一条消息标记已读，后端验证归属并单调推进，不能用客户端当前时间跳过未收到的消息。

## HTTP 与 Socket

- GET/POST /api/conversations；GET /api/conversations/:id；POST /:id/join。
- GET/POST /:id/messages；POST /:id/read。统一 P2 identifier 识别和错误结构，每个接口检查会话权限。
- Socket handshake auth.identifier 解析到数据库身份；P1 匿名连接只保留 ping/pong，所有 P3 事件要求有效身份。
- conversation:join/leave、message:send/new/error、typing:start/stop；ack 带成功数据或统一错误。join/send/typing 不相信客户端 userId、sender 或 role。
- 每个会话 room 为 conversation:<id>；只有校验成功后才加入。只在数据库提交后广播完整 Message DTO，发送者不含 identifier。
- 用户通知 room 用于给 Owner 和参与者刷新侧栏/未读，不向其他同事广播会话信息；不依赖是否打开会话才知道新消息。
- typing 不持久化，节流及短期超时清除；离开、断线时清理。重连重新入当前 room 并以 HTTP 补齐错过消息，按 id 合并去重。

## 前端

- 复用 useIdentity 和 IdentityDialog，身份有效后挂载 ChatShell；保留 Owner 项目设置。
- 简化 ChatGPT 布局：页头 Egent/当前身份，左侧新聊天和可折叠项目分组，右侧聊天区及固定输入区；窄屏侧栏可收起。
- 只显示有当前用户可见历史的项目组，项目组按最新会话 updatedAt 降序，组内同样降序。
- 新聊天先打开项目选择 Dialog，调用现有 /api/projects；无可选项目和配置错误给出明确反馈。
- 会话最近 50 条默认滚到底部，加载更早消息保持阅读位置。仅接近底部或本人发送时自动滚动。
- 纯文本 React 渲染，无 HTML/Markdown 注入；Enter 发送、Shift+Enter 换行，输入法组合期间不发送。
- 消息待发送/失败/重试保留同一个 clientMessageId；离线不伪装成功，切换会话不串消息。
- 头像区分同事、Owner、Egent/系统，AGENT 仅渲染预留，不伪造 Agent 活动。
- typing 提示、未读标记与读取确认；页面后台不自动标记已读。P1 health/Socket 检查移到简洁基础设施区域，不删除其能力。
