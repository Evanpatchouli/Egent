## 设计决定

- User：UUID id、唯一字符串 identifier、name、OWNER/COLLEAGUE role、时间戳。migration 添加 WHERE role = 'OWNER' 的部分唯一索引，数据库防并发双 Owner。
- 名称 trim 后按 Unicode code point 校验 1–64 字符；identifier 严格按每 code point 7 位数字编码。同名返回 409，不添加随机后缀改变指定算法。反解校验纯数字、7 位长度、有效 Unicode 范围。
- ProjectSetting：projectPath 字符串主键、colleagueVisible 默认 false、时间戳。只存可见性覆盖，不保存项目注册表。
- LAN：读取 os.networkInterfaces 的有效私有 IPv4 和 netmask，按实际子网匹配来源 IPv4，支持 IPv4-mapped IPv6；不是硬编码 /24。localhost 不自动归为 Owner。
- TRUST_PROXY 默认 false；启用后通过 Koa 的 proxyIpHeader/proxyMaxIpsCount 明确读取可信代理 header，默认 X-Forwarded-For、最靠近服务端的一个代理地址，可配置为 X-Real-IP。README 说明代理必须覆盖 header 且限制直连。
- DEV_OWNER 默认 false，仅 NODE_ENV=development 且 loopback 来源时有效；生产环境拒绝启用。请求参数不能更改角色。
- IP 只决定 bootstrap、创建身份和现有 Owner 关联；后续 API 统一根据 X-Egent-User-Identifier 查询数据库，不重新按 IP 改角色。
- GET /api/bootstrap：支持已有 identifier 验证，返回 initialized、初始化 role、ownerExists。无效 identifier 返回统一 401，前端清除后重新 bootstrap；网络/500 不清除身份。
- POST /api/users 创建；GET /api/users/selectable 永远只返回 Colleague；POST /api/users/owner/associate 仅 Owner 初始化网络可关联已有 Owner；GET /api/me 返回数据库身份。
- GET /api/projects：读取 homedir/.codex/config.toml 的 projects 表，通过可靠 TOML parser 获取路径；每次请求重新读取保证变更生效，不读取其他配置字段到响应/日志。
- PUT /api/projects/visibility：JSON body 传 projectPath、colleagueVisible，避免 Windows 路径放 URL 路由；数据库查询角色且确认路径仍在 config 中后才 upsert。
- Windows 路径保留 config 原值作为主键，不生成 UUID、不扫描目录；名称从路径 basename 推导。旧设置可保留，但不在 config 的项目永远不返回。文件缺失、不可读、语法错误以统一可理解错误返回，不崩溃、不输出 TOML 原文。
- identifier 是可逆、可复制的身份标记，不是保密认证令牌；按用户要求不加入密码/JWT。权限来自所引用的数据库身份，不能保证持有他人 identifier 的客户端不可冒用。

## 分步文件范围

1. 数据库和共享契约
   - packages/database/prisma/schema.prisma：User、Role、ProjectSetting。
   - packages/database/prisma/migrations/*：建表及 Owner 部分唯一索引；prisma.config.ts 和 package.json 添加 migration 入口。
   - packages/shared/src/identity.ts、api.ts、index.ts：编码函数、localStorage/header 常量、用户/bootstrap/project/error 类型。
2. 后端
   - apps/server/src/config.ts：proxy 与开发开关配置。
   - src/network.ts：网卡过滤、来源 IP 和子网比较。
   - src/errors.ts、middleware/identity.ts：统一错误、identifier 查询与 Owner 要求。
   - src/services/users.ts、codex-projects.ts、projects.ts：简单用户和项目操作，无 repository framework。
   - src/routes/bootstrap.ts、users.ts、me.ts、projects.ts：新增 API。
   - src/app.ts、server.ts：挂载新路由、CORS 增加 PUT 和身份 header，保留 health/Socket。
3. 前端
   - apps/web/src/api/client.ts、identity.ts、projects.ts：身份 header、统一错误和接口请求。

   - src/components/IdentityDialog.tsx、ProjectSettingsDialog.tsx、ProjectList.tsx：Material Tailwind Dialog/Input/Button/Checkbox；初始化不可 Esc/外部点击跳过。
   - src/App.tsx：左侧项目、右侧 Owner 设置、用户信息；保留 P1 健康和 Socket 测试能力，不做 Chat。
