## 兼容性发现与已批准决策

- npm 元数据实测：@material-tailwind/react 2.1.10 peer 仅 React 16/17/18；3.0.0-beta.24 声明 React >=18。建议仅该组件库采用固定 beta 版本，保留 React 19，并在实施中验证真实渲染、按钮点击与控制台，README 记录预发布例外。
- beta 仍依赖 @tanstack/react-ranger 0.0.4，其 peer 未声明 React 19；因此不能视为完全兼容。实施先做最小组件运行验证，记录传递 peer 风险，不全局关闭 peer 校验；若失败则报告证据和替代方案。
- npm 元数据实测：Prisma 7.10.0 支持 Node ^20.19 || ^22.12 || >=24.0。建议固定 7.10.0 与同版本 adapter/client，避开 latest 指向的预发布版本。官方该版本 CLI 源码默认允许无 model，实施时实际 generate 验证。
- 兼容性核对只读委派给子智能体，主智能体复核；不使用外部 DSH，以避免其会话文件写出授权目录。
